# Introduction

This repository contains the patch set to support TDX device passthrough, including Linux and QEMU patches. It was used to help customers backport the TDX patches to their older codebases. Since all the patches have been merged into the upstream code, and the customers have finished the backporting, this repository is archived for future reference.
